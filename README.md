# 🩸 Sickle-Cell Awareness & Support Platform 

A web-based project that teaches people about sickle-cell and offer support to those who are suffering from it
A Django-based website that creates awareness about sickle-cell disease, supports affected individuals, and enables donations to fund outreach programs.

# 🌍 Project Overview
This platform is built to:

- Educate the public about sickle-cell disease  
- Provide support resources for patients and families  
- Share personal stories for awareness  
- Allow community donations to support affected individuals  
- Build a safe online community

# 🚀 Features
# Public Features
- 🏠 Home page with awareness message  
- 📘 About sickle-cell disease  
- ❤️ How to support patients  
- 💸 Donation page (M-Pesa)  
- 📞 Contact page


# User Features
- 👤 User registration & login  
- ✍️ Submit personal stories  
- 📚 Read articles posted by admin 

 # Admin Features
- Manage stories  
- Publish awareness articles  
- Track donations

 # 🛠️ Technologies Used
- Python 
- Django 
- Bootstrap 5
- M-Pesa Daraja API
